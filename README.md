Library Management API
A lightweight RESTful API built with FastAPI for managing a library's book inventory. This project supports full CRUD (Create, Read, Update, Delete) operations using an in-memory database.
Features
FastAPI framework for high performance and automatic interactive documentation.
Pydantic data validation to ensure correct data formats.
In-memory storage requiring no database setup to run.
Complete CRUD operations for managing books.
API Endpoints
Method
Endpoint	Description
GET	/books	Retrieve all books in the library
GET	/books/{book_id}	Find a specific book by its ID
POST	/books	Add a new book to the library
PUT	/books/{book_id}	Update existing details of a book
DELETE	/books/{book_id}	Remove a book from the system
Installation and Setup
1. Clone the Repository
bash
git clone https://github.com
cd your-repo-name
Use code with caution.

2. Create a Virtual Environment
bash
python -bin venv venv
source venv/bin/activate  # On Windows use: venv\Scripts\activate
Use code with caution.

3. Install Dependencies
bash
pip install fastapi uvicorn
Use code with caution.

4. Run the Application
Save your code in a file named main.py and run:
bash
uvicorn main:app --reload
Use code with caution.

The server will start running at http://127.0.0.1:8000.
